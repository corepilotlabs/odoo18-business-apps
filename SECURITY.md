# Security Policy

If you believe you found a security issue in a CorePilot Labs commercial Odoo product, please report it privately to:

**corepilotlabssupport@gmail.com**

Do not open a public issue containing exploit details, credentials, customer data, database content or other sensitive evidence.

Please include the affected product, Odoo version, impact, reproduction steps where safe, and a way to contact you for follow-up.

This public repository contains product documentation and marketing material only. Commercial implementation source code remains private.
