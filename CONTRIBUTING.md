# Contributing and Product Feedback

This repository is the public product-information layer for CorePilot Labs Odoo applications. Commercial implementation source code is maintained privately.

We welcome:

- product use-case suggestions
- feature requests
- documentation corrections
- questions about supported workflows
- reproducible reports about public documentation or examples

For customer-specific support, licensing, private evidence or security matters, contact **corepilotlabssupport@gmail.com**.

## Before opening a public issue

Do not include credentials, API keys, database dumps, invoices containing confidential data, employee/customer information or production logs with sensitive content.

A useful request explains the business problem first, then the desired outcome. This helps us evaluate whether the request belongs in an existing product or should remain outside the product scope.
