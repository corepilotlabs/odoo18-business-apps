# CorePilot Labs Support

Commercial product support and product questions are handled through:

**corepilotlabssupport@gmail.com**

When contacting support, include the product name, Odoo version, a concise description of the issue and any non-sensitive screenshots that help reproduce the problem.

## Please do not publish sensitive data

Do not post database dumps, credentials, API keys, private invoices, customer records, employee data or production logs containing confidential information in this public repository.

For commercial source-code matters, customer-specific incidents or private evidence, use the support email instead of a public GitHub issue.
