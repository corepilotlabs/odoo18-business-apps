# NEXORA Store — Public Static Frontend

This folder is the public storefront copy of NEXORA Demand Store.

## Public-safe scope

- Static storefront only.
- No NEXORA OS private runtime code.
- No PayPal credentials or merchant email.
- Paid products require a real PayPal Payment Link before publication.
- Saudi Arabia remains excluded from proactive outbound marketing.
- White-label partner offers are shown only when a product is explicitly published, QA-passed and eligible.

## Current truth

- `Workflow Friction Checklist`: published and free.
- `Booking & Quote Workflow Automation`: validating, not for sale.
- `Excel / PDF Operations Automation`: validating, not for sale.
- White-label program: prepared, but there is currently no paid white-label-eligible product ready for partner ordering.

## Hosting

The repository is public, but GitHub Pages is currently disabled at repository level. This folder is ready to be served from GitHub Pages once Pages is enabled by an account/repository administrator.
