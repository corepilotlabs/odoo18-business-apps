# CorePilot Labs — Odoo Business Control Tools

> Detect problems earlier. Understand the evidence. Approve safely. Verify the result.

CorePilot Labs builds focused control applications for Odoo 19. The products are designed around real operational and accounting failure points rather than adding more screens for their own sake.

## Product line

| Product | Problem it solves | Odoo | Price |
|---|---|---:|---:|
| ERP Control Suite | Diagnose, control and verify ERP/accounting problems | 19.0 | $199 |
| Purchase Price Control | Detect price increases, compare vendors and control approvals | 19.0 | $99 |
| Smart Transaction Capture | Convert PDF/image transaction evidence into verified draft accounting documents | 19.0 | $149 |
| Inventory Close Control | Detect inventory-close risks before execution and verify the close afterward | 19.0 | $129 |

## Why CorePilot

We build around a controlled decision path:

**Detect → Explain → Evidence → Dry Run / Review → Approval → Execute → Verify**

Where a workflow can change accounting or operational data, the product should fail closed when evidence is incomplete or inconsistent.

## Public vs private

This showcase is intentionally documentation-first. Commercial source code remains private. Public material contains product explanations, screenshots, release evidence, safety controls, support information and links to the official Odoo Apps listings.
