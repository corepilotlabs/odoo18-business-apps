# CorePilot Labs — Odoo Business Control Tools

[![Public Showcase Quality](https://github.com/corepilotlabs/odoo18-business-apps/actions/workflows/showcase-quality.yml/badge.svg)](https://github.com/corepilotlabs/odoo18-business-apps/actions/workflows/showcase-quality.yml)

> Detect problems earlier. Understand the evidence. Approve safely. Verify the result.

CorePilot Labs builds focused control applications for Odoo 19. The products are designed around real operational and accounting failure points rather than adding more screens for their own sake.

> **Repository note:** this public repository was originally created for the Odoo 18 launch line; the current active showcase documents the Odoo 19 product line.

## Why CorePilot

We build around a controlled decision path:

**Detect → Explain → Evidence → Dry Run / Review → Approval → Execute → Verify**

Where a workflow can change accounting or operational data, the product should fail closed when evidence is incomplete or inconsistent.
